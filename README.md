# Curso de SQL de SQL Academy

¡Hola a todos!
Aquí encontrarás los textos del curso interactivo de SQL que se publica en [SQL Academy](https://sql-academy.org/es/guide).

Este repositorio se creó para que cualquiera pueda contribuir al desarrollo de este curso gratuito de SQL.

Si encuentras imprecisiones en los artículos o tienes propuestas de mejora, envíanos un pull request con tus cambios. También nos encantará recibir artículos nuevos 😉.
